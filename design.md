# Discord Components V2 — Waifu & Assassin UI Design

## Overview

Build a clean, premium Discord Components V2 UI system for a collection/game bot.

The UI should closely follow the visual language shown in the reference screenshots:

- Dark Discord-native appearance
- Minimal and clean
- No traditional Discord embeds
- Use Discord Components V2
- Strong hierarchy through text size/weight
- Thin separators between sections
- Images displayed as right-side accessories
- Small metadata labels
- Compact stat rows
- Rounded Discord-style container
- No unnecessary borders, boxes, gradients, or decorative ASCII
- Avoid making the UI look like a website
- It should feel like a native Discord bot component

There are two primary card types:

1. `WAIFU` — relationship/bond progression
2. `ASSASSIN` — character/unit progression

The two cards should share the same component design language but have different information architecture.
